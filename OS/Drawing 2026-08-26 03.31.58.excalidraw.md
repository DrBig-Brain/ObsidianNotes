# Types of OS
    -> Multi Programming OS:
    -> Batch OS
    -> Time Sharing OS
    -> Real Time OS
    -> Distributed OS
    -> Network OS
-> 1st Gen - No OS, 2nd gen - Magnetic Tapes No OS, 3rd Gen - Magnetic Disks Uniprogrammed and multi programmed OS
-> Ability of OS to hold single program in its memory makes it a Uni Program OS
    -> less efficiency, less throughput, cpu more idle
    -> Throughput -> no. of programs executed per unit time.
    -> Eg MS DOS
-> Multi Program OS : multiple ready to run program in memory
    -> at one time cpu will execute only one program in any case
    -> maximizes cpu utilization, Efficiency, Throughput.
    -> Impression of multiplexing of CPU among different programs
    -> Multitasking [Program (unix) = Task(windows)]
    -> A program / task in execution is called a prcess.
