# IPv4 Addressing (functionality of Network layer)
- Logical Address of 32 bits (4 Octets) 2^32 = 4 Billion
- Netword Id + Host Id
- Determinied by IANA (Internet Assigned Numbers Authority)
- Usually first 8 bits are Network ID and 24 bits are Host ID
- Network is the case and the Host is the subset such that each case has 2^24 subsets
- Thus 256 Networks have 2^24 hosts ~ 16 mil hosts (If an organization wants to own a network it need to purchase the whole 16 mil hosts Problematic).
- ClassFull Addressing
    - Telephone networks India - 11 digit number (STD + TID)
    - Cities (total cities less but people per city is more, total villages a lot but people per village is less).
    - For city 3bit to STD and 8 bits to TID for villages 5 bits to STD and 6 bit to TID.
    - Class 1 Less no. of Networks and more Large no. of hosts (for organizations like NASA)
    - Class 3 more no. of networks and less no. of Hosts (for schools and small orgs)
    - Class 2 MNC's like TCS and Wipro middlemen
    - Class A,B,C,E,D
- Class Less Addressing
    - 32 Bit IP adress
    - keep adding a bit and splitting int two sub classes ^csXdCJYx

- Representation of IP Addresses
    - Binary -> 11001000.11111100.00111111.11110111
    - Decimal -> 200.252.63.247
    - HexaDecimal -> C8.FC.3F.F7

- Loop back testing / Self Connectivity / Interprocess 
Communication
    - 127.x.x.x Reserved

- Class Identification:
    - Class A - 0 - 126 first Octet
    - Class B - 128 - 191
    - Class C - 192 - 223
    - Class D - 224 - 239
    - Class E - 240 - 255

# Subnetting and Borrowing bits

- Dividing a bigger network into smaller subnets
- Advantages
    - Easier Mantainance
    - Security
- Disadvantages
    - Identification becomes difficult.
    - In one network 2 ips are wasted (all 0s and all 1s) each subnet will have these two wasted
    - Expenses increase

- How do we create the subnets = borrowing the bits
    - Borrowing bits from HID called subnetting
    - 3 bits = 8 subnets  ^4sJGq5XC
